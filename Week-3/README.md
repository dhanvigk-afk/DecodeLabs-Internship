# 🤖 NextPick AI

## 📌 Project Description
NextPick AI is a simple AI-based Career Recommendation System developed using HTML, CSS, and JavaScript. It recommends suitable career paths based on the user's interests and provides learning resources, recommended courses, YouTube channels, project ideas, and estimated salary information.

## ✨ Features
- Career recommendations based on selected interests
- Suggested skills to learn
- Recommended online courses
- Best YouTube channels for learning
- Project ideas for practice
- Estimated salary information
- Clean and responsive user interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## ▶️ How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` or open it in any web browser.
4. Select your interests and click **Get Recommendation**.
